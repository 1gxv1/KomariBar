# KomariBar

面向 Komari 的开源原生 macOS 菜单栏监控客户端，界面使用中文。

项目处于首版开发阶段，目前尚未发布可供下载的版本。

## 首版目标

- 菜单栏快速查看多台服务器，支持服务器切换。
- 展示 CPU、内存、磁盘、上下行速度和历史曲线。
- 展示网络累计用量、配额和进度；确认 Agent 月重置配置后显示账期用量。
- 提供明确标注的示例模式，在没有 Komari 实例时预览界面。
- 连接信息保存在本机，认证凭据存入 macOS 钥匙串。

## 技术方向

原生 SwiftUI 界面，通过 Komari 官方接口读取数据。VPS 上的数据采集和保存由独立部署的 Komari 服务端与 Agent 负责。

本项目是独立的第三方客户端，与 Komari 官方没有隶属关系。
